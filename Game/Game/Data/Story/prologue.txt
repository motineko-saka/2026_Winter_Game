// @bg village
// @bgm theme

#
朝の光が差し込んでいる。\n今日は、旅立ちの日だ。

@chara hakase hakase right
#博士
よく来たな。\n最初のパートナーを選んでくれ。

@choicecard "風タイプのシルフ" wind 001_flont "炎タイプのルファウ" fire 004_flont "水タイプのウィリュウ" water 007_flont
*wind
@give 1 5
@set starter = 1
@jump afterstarter

*fire
@give 4 5
@set starter = 2
@jump afterstarter

*water
@give 7 5
@set starter = 3
@jump afterstarter

*afterstarter
#博士
いい選択だ。\nさっそく、草むらで練習してみよう。

@hide hakase
#
野生のモンスターが飛び出してきた！

// 選んだ子に応じて相手を変える（starter: 1=風 2=炎 3=水）
@if starter == 1 enemy_water
@if starter == 2 enemy_wind
@if starter == 3 enemy_fire

*enemy_water
@battle 7 5
@jump afterbattle

*enemy_wind
@battle 1 5
@jump afterbattle

*enemy_fire
@battle 4 5
@jump afterbattle

*afterbattle
// battle_result: 1=勝ち 0=負け 2=逃げた 3=捕まえた
@if battle_result == 1 won
@if battle_result == 0 lost
@if battle_result == 3 caught
@jump escaped

*won
@chara hakase hakase right
#博士
見事だ！ 君ならきっと、いい旅ができる。
@jump fin

*caught
@chara hakase hakase right
#博士
おお、捕まえるとは！ 大したものだ。
@jump fin

*lost
@chara hakase hakase right
@heal
#博士
無理は禁物だ。\n手持ちを回復しておいたよ。
@jump fin

*escaped
@chara hakase hakase right
#博士
逃げるのも立派な判断だ。
@jump fin

*fin
#博士
では、行ってきなさい。
@hide hakase
@end
